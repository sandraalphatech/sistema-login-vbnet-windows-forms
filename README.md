# Sistema de Login — VB.NET Windows Forms
Aplicação desktop desenvolvida em VB.NET e Windows Forms, com uma interface gráfica inspirada na experiência de aplicações mobile.
O projeto reúne um sistema de autenticação, dashboard de utilizador, calculadora e conversor de temperatura numa aplicação integrada.

## Funcionalidades
- Sistema de login
- Validação de utilizador e palavra-passe
- Dashboard de utilizador
- Navegação entre diferentes funcionalidades
- Calculadora
- Conversor de temperatura
- Conversão entre Celsius, Fahrenheit e Kelvin
- Botão de voltar entre ecrãs
- Sistema de logout
- Interface gráfica personalizada
- Feedback visual através de botões e campos de entrada

## Tecnologias

- Programação orientada a eventos

## Interface
A aplicação foi desenvolvida com uma interface visual personalizada, utilizando cores, botões, campos de entrada, cartões e elementos gráficos para criar uma experiência semelhante à de uma aplicação mobile.

## Funcionalidades da aplicação

### Login
Ecrã inicial destinado à autenticação do utilizador, com campos para utilizador e palavra-passe e opções de entrada e saída.

### Dashboard
Após o login, o utilizador é direcionado para um painel principal com identificação do utilizador e acesso às funcionalidades disponíveis.

### Calculadora
Calculadora integrada na aplicação para realização de operações matemáticas básicas.

### Conversor de Temperatura
Ferramenta para conversão de temperaturas entre:
- Celsius
- Fahrenheit
- Kelvin
